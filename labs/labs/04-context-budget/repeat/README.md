# Повторение: обрезка с заметкой

**Задача:** `compactHistory` в `src/budget-2.ts`. Агент поддержки часами разбирает тикеты через инструмент `read_ticket`, история пухнет. Нужно ужать её под бюджет окна так же честно, как в лабе, но оставить след: в первое сообщение (задачу) дописать заметку `[обрезано K сообщений]`, чтобы модель знала, что часть разговора выкинута, и не выдумывала, будто видит всё.

Отличия от лабы. Закреплена не одна последняя пара, а `keepRecent` последних пар (по умолчанию 1). Заметку нельзя вставить отдельным сообщением: между задачей (user) и оставшимся хвостом (начинается с assistant) нет места для третьей роли, поэтому она идёт последним text-блоком задачи, а `content` задачи бывает строкой или массивом блоков. И главное: заметка сама занимает токены, причём её длина зависит от K, так что «влезло» проверяется уже с заметкой.

## Что проверяют тесты

- **Влезает** → история возвращается как есть, `dropped = 0`, заметки нет.
- **Не влезает** → выкинуты самые старые пары, хвост не тронут, первое сообщение стало `[{ text: задача }, { text: '[обрезано 4 сообщений]' }]`.
- **Заметка стоит токенов**: если без неё хватило бы одной пары, с ней режутся две.
- **Бюджет** это окно минус `max_tokens` минус `system`; на любом бюджете результат влезает и проходит проверки API (чередование ролей, нет сиротских `tool_result`), иначе `BudgetError`.
- **keepRecent**: последние N пар не трогаются; если без них не влезть, это `BudgetError`.
- **Задача массивом блоков**: исходные блоки на месте, заметка добавлена последним.
- **Без мутаций**: ни входной массив, ни первое сообщение не меняются.
- **Не влезает закреплённое** (задача, заметка, последние пары) или `system` + `max_tokens` съели окно → `BudgetError`.

## Подсказки

- Бюджет, `sizes` и быстрый выход это шаги 1-2 разбора без изменений; цикл по парам это шаги 3-4, только граница теперь `messages.length - 2 * keepRecent`, а не последняя пара.
- Заведи `withNote(k)`, которая собирает новое первое сообщение: блоки задачи (строку преврати в `{ type: 'text', text }`) плюс `{ type: 'text', text: trimNote(k) }`. Исходный массив блоков копируй, а не дописывай в него.
- В цикле после каждой снятой пары считай `size(withNote(from - 1)) + rest`, где `rest` это сумма размеров всех сообщений, начиная с `from`. Влезло: верни `[withNote(from - 1), ...messages.slice(from)]` и `dropped: from - 1`. Цикл кончился, а не влезло: `BudgetError`.
